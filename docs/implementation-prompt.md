## Ground rules

- **Branching:** work on a new `rewrite` branch created from `main`. The docs are currently uncommitted files on `main`'s working tree; commit them as the first commit on `rewrite`.
- **Commits:** commit at the end of each milestone, and at sensible points within one, with clear messages. **Don't push, open PRs or touch `main`** unless I ask.
- **Legacy code:** move the existing app into `legacy/` with `git mv` (it's the reference, and the Mongo migration script needs its types). It gets deleted at cutover, not by you.
- **Secrets:** `.env` holds the Mongo connection (`MONGO_CONNECTION_URL`, `MONGO_DATABASE`). Never print, log or commit secrets. Treat the Mongo data as **read-only**: never write to or delete from Mongo.
- **Library versions:** use current stable versions at install time. Check APIs against the installed versions and their docs, not memory. This applies especially to Drizzle, better-auth, Mantine, React Router, TanStack Query, Fastify and pg-boss.
- **External APIs:** be polite to Sleeper (stay well under 1000 calls/min; call `players/nfl` at most once a day and cache it). Cache every external response in `raw_payload` so re-runs don't re-fetch.
- **Code quality:** TypeScript strict, ESM, zod at every boundary. Keep the existing `.prettierrc` style. No `any` without a comment saying why.
- **Done means verified.** Each milestone ends with its checks actually run and passing: typecheck, lint, tests, and the specific verification listed. Report results honestly: what passed, what failed, what you skipped and why.

## Stack (doc §3.6, §3.10)

- pnpm workspaces + Turborepo, Node 24 LTS, Vitest.
- `packages/core`: domain types, metric and record definitions, pure compute.
- `packages/db`: Drizzle schema, migrations, the `migrate` entrypoint.
- `apps/api`: Fastify, zod, the record compiler, response cache, better-auth.
- `apps/ingest`: pg-boss worker. Sleeper sync, NFL reference data, ESPN bundle import, normalize → derive.
- `apps/scraper`: ESPN Playwright scraper. Headed, runs on a desktop, not containerized.
- `apps/web`: React + Vite, Mantine (current major), TanStack Query, React Router, Phosphor icons.
- Postgres 18. Migrations are generated by drizzle-kit, committed, and applied by drizzle-orm's `migrate()` in the one-shot `migrate` container. Views and functions drizzle-kit can't express go in custom migrations.
